# EventScout

## Project Overview

EventScout is a proposed React Native mobile application
that helps users search for upcoming events and access
event information through Ticketmaster Discovery API v2.

The application focuses on event discovery rather than
ticket bookings, payments or account management.

## Project Phase

Phase 1 - Project Proposal and UI Wireframes

The application implementation is planned for Phase 2.

## Project Objectives

- Develop a React Native mobile application.
- Integrate Ticketmaster Discovery API v2 using Axios.
- Implement at least three interactive screens.
- Support keyword search and optional city filtering.
- Display search results using FlatList.
- Implement React Navigation and React Hooks.
- Use reusable components and responsive Flexbox layouts.

## Proposed Screens

1. Home / Event Search
   - Keyword search
   - Optional city input
   - Search button

2. Event Listings
   - Live API search results
   - Event cards with images and details
   - Scrollable FlatList

3. Event Details
   - Selected event information
   - Date, time and venue
   - Official Ticketmaster event URL when available

## Third-Party API

Ticketmaster Discovery API v2

Documentation:
https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/

Planned endpoints:
- GET /discovery/v2/events.json
- GET /discovery/v2/events/{id}.json

A valid API key is required. API credentials will not
be committed to the repository.
